# WebAstral Project Rules

## Tech Stack
- Use Next.js App Router
- Use TypeScript
- Use Tailwind CSS
- Use functional React components
- Prefer server components unless client-side interaction is required

## Code Style
- Keep components modular and reusable
- Use clean and readable code
- Avoid unnecessary complexity
- Use meaningful variable and component names
- Keep files organized inside `src/`

## Styling
- Use Tailwind CSS only
- Avoid inline styles unless necessary
- Make layouts responsive by default
- Prefer utility classes over custom CSS

## Components
- Create reusable UI components
- Keep components small and focused
- Separate UI and logic when possible

## Performance
- Optimize images using Next.js Image component
- Avoid unnecessary client components
- Minimize re-renders
- Lazy load heavy sections if needed

## Folder Structure
- `src/app` → routes/pages
- `src/components` → reusable components
- `src/lib` → utilities/helpers
- `public` → static assets

## Best Practices
- Use semantic HTML
- Keep accessibility in mind
- Avoid deprecated APIs
- Follow latest Next.js conventions

## Important
- Do not generate outdated Pages Router code
- Use App Router conventions only
- Prefer modern Next.js patterns
